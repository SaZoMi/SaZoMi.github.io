Bachelor's thesisBachelorproef · 2026

Takaro MCP Server

A Model Context Protocol server that gives an LLM coding agent full access to the Takaro game-server management platform. Through 36 tools, the agent writes module code, pushes and installs it via the API, triggers commands and checks the resulting events, closing the whole develop–deploy–test loop without a human in between.

Een Model Context Protocol-server die een LLM-codeeragent volledige toegang geeft tot het Takaro-platform voor gameserverbeheer. Via 36 tools schrijft de agent modulecode, pusht en installeert hij die via de API, triggert hij commando's en controleert hij de events die volgen: de volledige ontwikkel-deploy-testcyclus, zonder mens ertussen.
